# LaunchKit

> LaunchKit was a set of web-based tools for mobile app developers, built by Cluster Labs, Inc. in San Francisco and backed by GV. Its products included Screenshot Builder (App Store screenshots), Review Monitor (App Store review alerts), Sales Reporter, App Websites, and Super Users / Cloud Config via the LaunchKit iOS SDK. LaunchKit joined Google in 2016 and the code was released as open source under Apache 2.0. There is no live hosted LaunchKit API, developer portal, or documentation today — the remaining surface is a self-hostable codebase and an unmaintained iOS SDK.
